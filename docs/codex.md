# Codex 開発設定

## ファイルの役割

- `AGENTS.md`: コーディング規約、検証手順、応答方針。
- `.codex/config.toml`: このプロジェクトの Codex 設定。
- `docs/design.md`: 確定要件、設計案、未決事項。仕様に関わる作業前に読む。

## 初期設定

`project_doc_max_bytes = 32768` により、プロジェクト指示の読み込み上限を32KiBに設定する。設計書がこの設定だけで自動的に読み込まれるわけではないため、参照指示を `AGENTS.md` に置く。

モデル、承認方式、サンドボックス、ネットワーク設定はプロジェクト側で固定せず、利用者または管理環境の設定に従う。API キーや端末固有の絶対パスはコミットしない。

プロジェクトの `.codex/config.toml` は、Codex が信頼済みと認識したプロジェクトでのみ読み込まれる。信頼設定は利用者の環境で管理する。ファイル作成だけで、実行中のセッションへの反映を保証しない。

## 作業時の運用

1. `AGENTS.md` と対象範囲の設計を確認する。
2. 確定要件と提案を区別し、新しい判断は設計書へ記録する。
3. 変更に応じて整形、ビルド、テスト、静的検査を実行する。ソース未作成の段階では文書と設定を確認する。
4. 結果と未検証事項を報告する。未実行のチェックを成功扱いにしない。

設定キーと読み込み条件は [OpenAI 公式設定リファレンス](https://learn.chatgpt.com/docs/config-file/config-reference) を参照する。
